# Очистка и нормализация каталога ингредиентов

## 📋 Что делаем

1. **Удаляем:**
   - Тестовые продукты (с "тест", "Тестов" в названии)
   - Дубликаты (русские версии продуктов)
   - Устаревшие записи

2. **Приводим к единому языку:**
   - Основной язык: **польский (PL)**
   - Удаляем все русские дубликаты

3. **Нормализуем данные:**
   - Устанавливаем `defaultShelfLifeDays` для всех продуктов
   - Устанавливаем `defaultPricePerUnit` для всех продуктов
   - Проверяем консистентность `unit` (g, ml, pcs)

## 🚀 Как выполнить

### Вариант 1: Через Render Dashboard (РЕКОМЕНДУЕТСЯ)

1. Зайти в Render.com → PostgreSQL Database → Shell/Query
2. Скопировать и выполнить файлы по порядку:
   - `026_cleanup_step1_delete.sql` - удаление дубликатов
   - `026_cleanup_step2_update.sql` - установка значений по умолчанию

### Вариант 2: Через Go скрипт

```bash
# Установить DATABASE_URL
export DATABASE_URL="your_database_url_here"

# Запустить скрипт
go run cmd/cleanup_ingredients/main.go
```

### Вариант 3: Через psql клиент

```bash
psql $DATABASE_URL -f migrations/026_cleanup_step1_delete.sql
psql $DATABASE_URL -f migrations/026_cleanup_step2_update.sql
```

## 🔍 Установка значений по умолчанию

- `protein` (белки): **3 дня**

- `grain` (крупы): **365 дней**
- `condiment` (специи): **365 дней**
- `other` (прочее): **180 дней**

### defaultPricePerUnit по категориям:
- `protein`: **0.02 PLN/g** (~20 PLN/кг)
- `vegetable`, `grain`, `dairy`: **0.01 PLN/g** (~10 PLN/кг)
- `condiment`: **0.03 PLN/g** (~30 PLN/кг)
- `other`: **0.01 PLN/g**
