- `Ingredient.normalized_value` - нормализованные значения для поиска

### Примененные команды:
```sql
-- Пример добавления перевода
UPDATE "Ingredient" 
SET name_en = 'Watermelon', 
    name_ru = 'Арбуз' 
WHERE name_pl = 'Arbuz';

-- Обновление normalized_value
UPDATE "Ingredient"
SET normalized_value = LOWER(
    TRANSLATE(
        COALESCE(name_pl, name),
        'ąćęłńóśźżĄĆĘŁŃÓŚŹŻ',
        'acelnoszz ACELNOSZZ'
    )
);
```
