## 🎯 Architecture Decision

### Backend Decides:
```
Title (any language) → utils.GenerateCanonicalName() → English slug
"Яичница"            → "scrambled_eggs"
"Жареный лосось"     → "fried_salmon"
"Pasta Carbonara"    → "pasta_carbonara"
```

### Frontend Uses:
```
recipe.canonicalName     // For URLs, keys, internal logic
recipe.titles[lang]      // For display to users
```

### NOT Client-Driven:
```
❌ Client sends canonicalName → Backend validates
✅ Client sends title → Backend generates canonicalName
```
